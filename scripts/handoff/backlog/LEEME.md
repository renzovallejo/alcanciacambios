# Backlog

`tickets.csv` trae 29 historias en 6 épicas, en el orden recomendado de trabajo. Cada una tiene sus criterios de aceptación (letras A–G de `02-especificacion/criterios-de-aceptacion.md`) y las capturas de referencia.

- **Jira**: *Configuración del sistema → Importación externa → CSV*. Mapea «Título» → Resumen, «Descripción» → Descripción, «Prioridad» → Prioridad, «Etiquetas» → Etiquetas, «Épica» → Epic Name / Parent.
- **Linear**: *Settings → Import → CSV* (Title, Description, Priority, Labels).
- **Trello / Excel / Google Sheets**: se abre directo (UTF-8 con BOM, acentos correctos).

Sugerencia de orden: Épica 0 (base) completa primero; después 1 → 2 → 3 → 4 en paralelo por plataforma; la épica 5 acompaña a todas.
